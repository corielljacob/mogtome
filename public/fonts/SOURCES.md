# Self-hosted navigation typography

Lora is served locally as unmodified WOFF2 files from Google's official font CDN.
It is licensed under the SIL Open Font License 1.1. The complete license is
included beside the files.

The MogTome wordmark is separate original SVG lettering in
`src/shared/ui/MogTomeWordmark.tsx` and `public/mogtome-wordmark.svg`, with no
web-font dependency.

Downloaded on 2026-09-28 from the
[official Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Lora:wght@400..700&display=swap).
The CSS uses the original Unicode ranges, so the browser downloads the extended
Latin subset only when it is needed.

## Lora

- Designer: Cyreal; copyright The Lora Project Authors.
- Style: normal, variable weight axis 400–700.
- Local Latin file: `lora-latin-400-700-normal.woff2` (37,788 bytes).
- [Official Latin WOFF2 source](https://fonts.gstatic.com/s/lora/v37/0QIvMX1D_JOuMwr7Iw.woff2).
- Local extended Latin file: `lora-latin-ext-400-700-normal.woff2` (20,088 bytes).
- [Official extended Latin WOFF2 source](https://fonts.gstatic.com/s/lora/v37/0QIvMX1D_JOuMwT7I-NP.woff2).
- [Google Fonts repository and metadata](https://github.com/google/fonts/tree/main/ofl/lora).
- Repository source filename: `Lora[wght].ttf`; metadata confirms the 400–700 axis.
