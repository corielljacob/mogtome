# Nook decorations

These are existing, artist-made Glitch game assets, not generated artwork.
Downloaded 28 September 2026. Original SVG artwork is retained without recoloring
or redrawing; filenames were shortened for this project. The three furniture SVGs
received `viewBox` attributes matching their original dimensions so they scale
correctly in responsive layouts. The illustration paths are unchanged.

Glitch was created by Tiny Speck. Tiny Speck dedicated the included game artwork
to the public domain under **CC0 1.0 Universal**. Its logo and trademark are not
included in that grant. Source license statement:
<https://github.com/tinyspeck/glitch-items#license>

License: <https://creativecommons.org/publicdomain/zero/1.0/>

Bart; furniture SVG cleanup by Anarres.” Credit is appreciated, not required by CC0.
